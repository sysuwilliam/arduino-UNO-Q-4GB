有官方库，但不是你刚才以为的那种“可直接 beginText()/print() 显示文字”的库。

对 UNO Q 来说，官方提供的是 Arduino_LED_Matrix，它能做的是：

  • matrix.draw(frame) 显示一张 8x13 自定义图
  • matrix.loadSequence(...) + matrix.playSequence() 播放动画序列

它没有你这次编译里用到的这些接口：

  • beginText()
  • print()
  • textScrollSpeed()

所以结论是：

  • 官方有库
  • Arduino IDE / App Lab 也支持
  • 但 UNO Q 这版库偏底层，主要是“点阵帧显示/动画播放”
  • 官方没给你这个板子提供现成的文字显示 API

你可以把它理解成： 官方给了“屏幕驱动和显示接口”，但没给 UNO Q 这一版提供“高级文字排版函数”。

如果你要显示数字、字母、单词，通常有两种办法：

  1. 自己把字符做成 8x13 点阵数组，然后 matrix.draw(...)
  2. 自己写一套小字库，把 A、B、1、2 转成像素点

如果你愿意，我可以下一步直接帮你写一个 UNO Q 专用的字母数字显示小库，让你以后能这样用：

showChar('A');
showNumber(7);
showText("SUN");

这样就相当于补上官方没有给你的那层功能。
