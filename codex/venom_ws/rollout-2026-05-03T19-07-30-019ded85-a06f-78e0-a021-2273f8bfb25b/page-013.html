ros2 node list | grep -E "controller_server|velocity_smoother"

ros2 param get /controller_server FollowPath.max_vel_x
ros2 param get /controller_server FollowPath.max_vel_theta
ros2 param get /controller_server FollowPath.acc_lim_theta
ros2 param get /controller_server FollowPath.weight_kinematics_forward_drive
ros2 param get /controller_server FollowPath.weight_kinematics_turning_radius

ros2 param set /controller_server FollowPath.max_vel_x 2.2
ros2 param set /controller_server FollowPath.max_vel_theta 1.0
ros2 param set /controller_server FollowPath.acc_lim_theta 1.0
ros2 param set /controller_server FollowPath.weight_kinematics_forward_drive 50.0
ros2 param set /controller_server FollowPath.weight_kinematics_turning_radius 60.0

ros2 param set /velocity_smoother max_velocity "[2.2, 0.0, 1.0]"

横着切弯优先调这几类：降低入弯速度、增强车头贴路径、增强非全向/转弯半径约束。

按这个顺序来，先一组一组试。

1. 先让车头跟得上弯

ros2 param set /controller_server FollowPath.max_vel_theta 1.2
ros2 param set /controller_server FollowPath.acc_lim_theta 1.2

ros2 param set /velocity_smoother max_velocity "[2.2, 0.0, 1.2]"
ros2 param set /velocity_smoother max_accel "[2.2, 0.0, 1.2]"
ros2 param set /velocity_smoother max_decel "[-2.2, 0.0, -1.2]"

如果调完开始自转，就降回：

ros2 param set /controller_server FollowPath.max_vel_theta 1.0
ros2 param set /controller_server FollowPath.acc_lim_theta 1.0

2. 增强不允许横着切的约束

ros2 param set /controller_server FollowPath.weight_kinematics_forward_drive 80.0
ros2 param set /controller_server FollowPath.weight_kinematics_turning_radius 100.0
ros2 param set /controller_server FollowPath.weight_kinematics_nh 1500.0

如果变得很慢或绕不过弯，把转弯半径权重降一点：

ros2 param set /controller_server FollowPath.weight_kinematics_turning_radius 70.0

3. 让轨迹更贴全局路径

ros2 param set /controller_server FollowPath.weight_viapoint 8.0
ros2 param set /controller_server FollowPath.global_plan_viapoint_sep 0.3

如果局部轨迹变得抖，把 weight_viapoint 降到：

ros2 param set /controller_server FollowPath.weight_viapoint 5.0

4. 降低入弯速度

如果还是横着切，说明速度对当前角速度太高：

ros2 param set /controller_server FollowPath.max_vel_x 1.8
ros2 param set /controller_server FollowPath.acc_lim_x 1.8

ros2 param set /velocity_smoother max_velocity "[1.8, 0.0, 1.2]"
ros2 param set /velocity_smoother max_accel "[1.8, 0.0, 1.2]"
ros2 param set /velocity_smoother max_decel "[-1.8, 0.0, -1.2]"

5. 确认 y 方向没被打开

ros2 param get /controller_server FollowPath.max_vel_y
ros2 param get /controller_server FollowPath.acc_lim_y
ros2 param get /velocity_smoother max_velocity

应该是：

max_vel_y = 0.0
acc_lim_y = 0.0
max_velocity 第二个数 = 0.0

我建议你先试这一组基线：

ros2 param set /controller_server FollowPath.max_vel_x 1.8
ros2 param set /controller_server FollowPath.acc_lim_x 1.8
ros2 param set /controller_server FollowPath.max_vel_theta 1.2
ros2 param set /controller_server FollowPath.acc_lim_theta 1.2
ros2 param set /controller_server FollowPath.weight_kinematics_forward_drive 80.0
ros2 param set /controller_server FollowPath.weight_kinematics_turning_radius 100.0
ros2 param set /controller_server FollowPath.weight_viapoint 8.0
ros2 param set /controller_server FollowPath.global_plan_viapoint_sep 0.3

ros2 param set /velocity_smoother max_velocity "[1.8, 0.0, 1.2]"
ros2 param set /velocity_smoother max_accel "[1.8, 0.0, 1.2]"
ros2 param set /velocity_smoother max_decel "[-1.8, 0.0, -1.2]"

这组会比现在稳，但速度会稍慢一点。调好后再逐步把 max_vel_x 从 1.8 -> 2.0 -> 2.2 往上加。

ros2 param set /controller_server FollowPath.max_vel_theta 1.2
ros2 param set /controller_server FollowPath.acc_lim_theta 1.2
ros2 param set /velocity_smoother max_velocity "[2.2, 0.0, 1.2]"

如果想写成多行，必须用反斜杠 \ 续行：

ros2 param set /controller_server \
  FollowPath.max_vel_theta \
  1.2
