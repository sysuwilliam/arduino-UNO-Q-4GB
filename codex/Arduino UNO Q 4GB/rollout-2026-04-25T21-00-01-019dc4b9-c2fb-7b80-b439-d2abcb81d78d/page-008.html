  • USB Composite Device: USB Camer
  • 对应 /dev/video4 和 /dev/video5

电脑自带摄像头是这个：

  • HD Webcam: HD Webcam
  • 对应 /dev/video0 /dev/video1 /dev/video2 /dev/video3

所以你后面要测试外接 USB 摄像头时，优先用 video4，也就是：

/dev/video4

你前面那次 v4l2-ctl -d /dev/video0 --list-formats-ext 实际测到的是电脑自带摄像头，不是你刚买的 USB 摄像头。这个要纠正过来。

v4l2-ctl -d /dev/video4 --list-formats-ext

ffplay /dev/video4

ffplay -f video4linux2 -input_format mjpeg -video_size 1280x720 /dev/video4

python3 - <<'PY'
import cv2

cap = cv2.VideoCapture(4)
cap.set(cv2.CAP_PROP_FOURCC, cv2.VideoWriter_fourcc(*'MJPG'))
cap.set(cv2.CAP_PROP_FRAME_WIDTH, 1920)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 1080)

print("opened:", cap.isOpened())
print("width:", cap.get(cv2.CAP_PROP_FRAME_WIDTH))

ret, frame = cap.read()
print("ret:", ret)
if ret:

cap.release()
PY
