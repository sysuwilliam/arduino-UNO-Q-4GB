# 矩形中心检测系统 - 方案2（评分机制算法）

基于 OpenCV 的动态矩形中心检测系统，在 Arduino UNO Q Debian 主机上运行。

**算法来源**：移植自视觉代码项目的 CenterGet 算法，采用评分机制选择最佳矩形。

## 功能特性

- **实时矩形检测**：检测图像中的矩形区域并提取顶点坐标
- **多重验证**：6重筛选条件（面积、顶点、边界、角度、边长比例、面积阈值）
- **评分机制**：角度得分(60%) + 面积得分(40%)，选择最佳矩形
- **中心计算**：计算矩形的几何中心（对角线交点）
- **偏差计算**：计算矩形中心与图像中心的偏差
- **Web界面**：提供浏览器实时预览和参数调整

## 算法特点

### 多重验证（6重筛选）

| 验证项 | 条件 | 说明 |
|--------|------|------|
| 面积过滤 | 面积 > 500 | 去除小噪声 |
| 顶点数筛选 | 顶点数 = 4 | 只保留四边形 |
| 边界检查 | 距离边界 > 5px | 过滤不完整轮廓 |
| 角度验证 | 70° < 角度 < 110° | 验证接近直角 |
| 边长比例 | max/min ≤ 5 | 过滤极端狭长四边形 |
| 面积阈值 | 面积 > S_THRESHOLD | 最终筛选 |

### 评分机制（创新点）

**角度得分：**
```
角度偏差 = Σ|角度 - 90°| / 4
角度得分 = 100 - 角度偏差
```

**面积得分：**
```
面积得分 = min(100, (面积 / 最大可能面积) × 100)
```

**综合得分：**
```
总得分 = 0.6 × 角度得分 + 0.4 × 面积得分
```

**权重说明：**
- 角度权重 60%：更看重形状是否规则
- 面积权重 40%：兼顾目标大小

### 优势

- ✅ **避免误检**：评分机制避免只选择面积最大的矩形
- ✅ **平衡精度**：平衡角度精度和面积大小
- ✅ **鲁棒性好**：适应不同大小、位置、角度的矩形

## HTTP 端点

- `/` - Web 预览页面
- `/stream.mjpg` - MJPEG 视频流
- `/snapshot.jpg` - 单帧 JPEG 快照
- `/health` - 健康检查
- `/result.json` - 检测结果（JSON格式）
- `/config` - 配置信息（JSON格式）
- `/threshold/increase` (POST) - 增加面积阈值
- `/threshold/decrease` (POST) - 减少面积阈值

## 结果格式

`/result.json` 示例：

```json
{
  "status": "streaming",
  "rect_detected": true,
  "center": [320, 240],
  "error": [0, 0],
  "vertices": [[100, 100], [540, 100], [540, 380], [100, 380]],
  "area": 152000,
  "score": 95.5,
  "s_threshold": 2000
}
```

字段说明：
- `status`: 当前状态
- `rect_detected`: 是否检测到标准矩形
- `center`: 矩形中心坐标 [x, y]
- `error`: 与图像中心的偏差 [dx, dy]
- `vertices`: 矩形四个顶点坐标
- `area`: 矩形面积
- `score`: 检测得分（0-100）
- `s_threshold`: 当前面积阈值

## 图像处理流程

```
输入图像 → 灰度化 → 高斯模糊 → 二值化 → Canny边缘检测 → 轮廓查找 
→ 多边形拟合 → 多重验证 → 评分机制 → 选择最佳矩形 → 中心计算 → 结果可视化
```

详细步骤：
1. **灰度化**：减少计算量（3通道→1通道）
2. **高斯模糊**：平滑噪声，避免边缘检测时的噪声干扰
3. **二值化**：根据阈值144，将像素分为黑白两类，突出目标轮廓
4. **Canny边缘检测**：提取图像中的边缘信息
5. **轮廓查找**：从边缘图像中提取所有轮廓
6. **多边形拟合**：使用Douglas-Peucker算法将轮廓拟合为多边形
7. **多重验证**：
   - 面积过滤：面积 > 500
   - 顶点数筛选：顶点数 = 4
   - 边界检查：距离边界 > 5px
   - 角度验证：70° < 角度 < 110°
   - 边长比例：max/min ≤ 5
8. **评分机制**：计算角度得分和面积得分，综合评分
9. **选择最佳矩形**：选择评分最高的矩形
10. **中心计算**：计算两条对角线的交点作为矩形中心
11. **结果可视化**：绘制矩形边框、顶点、中心点及坐标信息

## 可调参数

### 图像预处理参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| threshold_value | 144 | 二值化阈值 |
| canny_low_threshold | 50 | Canny边缘检测低阈值 |
| canny_high_threshold | 150 | Canny边缘检测高阈值 |
| gaussian_blur_size | 5 | 高斯模糊核大小 |

### 矩形验证参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| min_area | 500 | 最小面积 |
| border_threshold | 5 | 边界距离阈值 |
| angle_min | 70 | 最小角度 |
| angle_max | 110 | 最大角度 |
| max_length_ratio | 5 | 最大边长比例 |

### 面积阈值参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| S_THRESHOLD | 2000 | 面积阈值 |
| THRESHOLD_MIN | 500 | 最小阈值 |
| THRESHOLD_MAX | 10000 | 最大阈值 |
| THRESHOLD_STEP | 500 | 调整步长 |
