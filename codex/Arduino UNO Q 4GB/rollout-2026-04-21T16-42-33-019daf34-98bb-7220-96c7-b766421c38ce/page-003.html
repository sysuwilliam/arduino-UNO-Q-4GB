这段代码有两个问题。

第一，Moniter.print(i); 拼错了，应该是 Monitor.print(i);，不是 Moniter。

第二，int i = 1; 写在函数里面，所以每次调用 set_led_state() 时都会重新变成 1。因此你即使后面写了 i++;，下次进来它还是从 1 开始，达不到计数效果。

也就是说你现在这段代码实际效果接近于：

  • LED 会正常控制
  • 每次都打印 1
  • i++ 基本没意义

如果你只是想打印一次固定值，可以这样写：

void set_led_state(bool state) {
    digitalWrite(LED_BUILTIN, state ? LOW : HIGH);
    int i = 1;
    Monitor.print(i);
}

如果你想让 i 每次调用都递增，应该写成：

void set_led_state(bool state) {
    static int i = 1;
    digitalWrite(LED_BUILTIN, state ? LOW : HIGH);
    Monitor.print(i);
    i++;
}

这里的 static 表示这个变量不会在每次函数结束后丢失，会保留上一次的值。

这样写 i 不会累计。

原因和你刚才 .ino 里那个 int i = 1; 一样：

def loop():
    i = 0
    ...
    i += 1

每次进入 loop() 时，i 都重新变成 0，然后加 1，所以你每次打印出来都会是：

True 1
False 1
True 1
False 1

也就是说：

  • led_state 会正常翻转
  • 但 i 永远都是 1

如果你想让 i 真正累计，要把它放到函数外面，像这样：

from arduino.app_utils import *
import time

led_state = False
i = 0

def loop():
    global led_state, i
    time.sleep(0.2)
    led_state = not led_state
    i += 1
    print(led_state, i)
    Bridge.call("set_led_state", led_state)

App.run(user_loop=loop)

这样效果就是：

  • 第一次打印：True 1
  • 第二次打印：False 2
  • 第三次打印：True 3
  • 第四次打印：False 4

因为这时 i 是全局变量，不会每次进入 loop() 都重置。

一句话总结：

  • 写在 loop() 里面：每次重新初始化
  • 写在 loop() 外面：才能跨多次循环累计

这个报错说明：

你在 loop() 里写了 i += 1，Python 把 i 认定为局部变量，但这个局部变量在当前函数里还没有先赋值，所以报错了。

核心原因是这类代码：

i = 0

def loop():
    i += 1

在 Python 看来：

  • 因为你写了 i += 1
  • 所以 i 被当成 loop() 里的局部变量
  • 但局部变量 i 在执行 i += 1 前并没有值
  • 所以报 UnboundLocalError

正确写法有两种。

第一种，用全局变量：

from arduino.app_utils import *
import time

led_state = False
i = 0

def loop():
    global led_state, i
    time.sleep(0.2)
    led_state = not led_state
    i += 1
    print(led_state, i)
    Bridge.call("set_led_state", led_state)

App.run(user_loop=loop)

这里 global i 的意思是： “我在这个函数里操作的不是新的局部变量，而是外面的全局变量 i。”

第二种，不用全局变量，而是每次都在函数里重新定义：

def loop():
    i = 0
    i += 1

这不会报错，但每次结果都还是 1，因为它不会累计。

所以你现在想要“计数递增”，就应该用第一种。

一句话概括这次报错：

i += 1 让 Python 认为 i 是局部变量，但你又没先在函数里给这个局部变量赋初值。

如果你愿意，我可以接着给你解释为什么 led_state 要写 global led_state，而 time.sleep(0.2) 不需要。
