报错原因很直接：Monitor.print() 不是 printf()，它不支持这种格式化写法：

Monitor.print("%d\n", i);

你把它当成 C 语言的 printf("%d\n", i) 在用了，但 Arduino 这套 Print 接口不是这么设计的。

正确写法是分开写。

如果你只是想输出数字：

Monitor.print(i);

如果你想输出后换行：

Monitor.println(i);

所以你这里应该改成：

void set_led_state(bool state) {
    static int i = 1;
    digitalWrite(LED_BUILTIN, state ? LOW : HIGH);
    Monitor.println(i);
    i++;
}

如果你想带文字一起输出，也要拆开：

Monitor.print("i = ");
Monitor.println(i);

或者：

Monitor.print("count: ");
Monitor.println(i);

一句话区分：

  • printf("%d\n", i) 是 C 风格格式化输出
  • Monitor.print(i) / Monitor.println(i) 是 Arduino Print 类风格输出

你这次编译失败，就是因为 Monitor.print() 没有“字符串格式 + 参数”这种重载。

如果你愿意，我可以顺手给你列一个 print / println / printf 的区别小表。

这次是括号没配对，而且你的字符串拼接写法也不对。

你写的是：

问题有两个：

  2. "state: " + state 这种写法不对，C++ 里字符串字面量不能这样直接和 bool 拼

你如果想同时输出 state 和 i，最稳的写法是分开打印：

void set_led_state(bool state) {
    static int i = 1;
    digitalWrite(LED_BUILTIN, state ? LOW : HIGH);

    Monitor.print("state: ");
    Monitor.print(state);
    Monitor.print(" counter: ");
    Monitor.println(i);

    i++;
}

这样输出会类似：

state: 1 counter: 1
state: 0 counter: 2
state: 1 counter: 3

如果你想把 state 打印成 true/false，可以这样写：

void set_led_state(bool state) {
    static int i = 1;
    digitalWrite(LED_BUILTIN, state ? LOW : HIGH);

    Monitor.print("state: ");
    Monitor.print(state ? "true" : "false");
    Monitor.print(" counter: ");
    Monitor.println(i);

    i++;

state: false counter: 2

你现在先不要急着用 String(...) + ... + ... 这种拼接，先用连续 Monitor.print() 最稳，也最不容易报错。

不能简单说“自带 2 个串口”，更准确地说：

这个板子有两套运行环境、两套输出通道，你现在容易把它们混成“两个串口”。

在 UNO Q 里主要是这两个侧面：

  • Linux 侧：运行 main.py
  • MCU 侧：运行 sketch.ino

所以你现在看到的输出也分两类：

  • Python 的 print()：进 App Lab 的 Main (Python) 日志
  • sketch 的 Monitor.print()：进 App Lab 的 Sketch (Microcontroller) 日志

这不等于“板子只有两个硬件串口”，而是说：

  • Python 和 sketch 各有自己的日志通道
  • 它们在 App Lab 里被分开显示

另外你前面看到官方文档还提到：

  • Serial.println() 是 UART 串口输出
  • Monitor.print() 是给 App Lab Console 看的

所以至少要区分这两件事：

  • Serial 更接近传统串口
  • Monitor 更接近 App Lab 提供的调试输出接口

一句话总结：

不是简单的“板子自带 2 个串口”，而是 UNO Q 有 Linux 侧和微控制器侧两套运行环境，因此在 App Lab 里你会看到两套不同的日志输出路径。
