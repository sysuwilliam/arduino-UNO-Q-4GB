有，官方是提供的，但严格说不是 “Arduino IDE 自带驱动”，而是随对应开发板平台一起提供。

如果你说的是 Arduino UNO Q 4GB，官方资料明确写了它板上有一块 8×13 的单色蓝色 LED matrix（104 像素），由 STM32U585 驱动。
来源： - UNO Q 硬件页：https://docs.arduino.cc/hardware/uno-q - UNO Q 数据手册：https://docs.arduino.cc/resources/datasheets/ABX00162-ABX00173-datasheet.pdf

关于“驱动/库”这件事，官方论坛和官方核心仓库都表明： - UNO Q 使用的官方库名是 Arduino_LED_Matrix - 这个库不是单独靠 Library Manager 安装，而是由 Arduino Zephyr Boards / ArduinoCore-zephyr 平台提供

来源： - 官方核心仓库：https://github.com/arduino/ArduinoCore-zephyr - 官方论坛说明（UNO Q 已经自带该库）：https://forum.arduino.cc/t/cannot-install-arduino-led-matrix-library-for-arduino-uno-q/1411042

所以结论是：

  1. 官方提供了 UNO Q LED 点阵的支持。
  2. Arduino IDE 可以用，但前提是安装对应的板卡平台，不是只装一个裸 IDE。
  3. 对 UNO Q 来说，应安装 Arduino Zephyr Boards 平台，然后就能使用 Arduino_LED_Matrix。

你可以先试这种最基本的头文件方式：

可以，官方这块点阵最直接的做法是用 Arduino_LED_Matrix，然后用它继承的 ArduinoGraphics 文字接口来显示数字和字母。

官方依据： - UNO Q 硬件页：https://docs.arduino.cc/hardware/uno-q - ArduinoCore-zephyr 安装说明：https://github.com/arduino/ArduinoCore-zephyr - Arduino_LED_Matrix 头文件，里面能看到 begin()、clear()、endText()、textScrollSpeed() 等接口：https://raw.githubusercontent.com/arduino/ArduinoCore-zephyr/main/libraries/Arduino_LED_Matrix/src/Arduino_LED_Matrix.h

最小示例，显示一个字母和一个数字：

#include <Arduino_LED_Matrix.h>

Arduino_LED_Matrix matrix;

void setup() {
  matrix.begin();
  matrix.clear();

  matrix.beginText(0, 1);   // 起始位置
  matrix.print("A7");       // 直接显示字母数字
  matrix.endText();         // 输出到点阵
}

void loop() {
}

如果你想显示变量里的数字：

#include <Arduino_LED_Matrix.h>

Arduino_LED_Matrix matrix;
int value = 42;

void setup() {
  matrix.begin();
}

void loop() {
  matrix.clear();

  matrix.beginText(0, 1);
  matrix.print(value);      // 显示数字 42
  matrix.endText();

  delay(1000);
  value++;
}

如果内容太长，屏幕放不下，就让它滚动：

#include <Arduino_LED_Matrix.h>

Arduino_LED_Matrix matrix;

void setup() {
  matrix.begin();
  matrix.clear();

  matrix.beginText(13, 1);      // 从右边外侧开始
  matrix.print("HELLO 123");
  matrix.textScrollSpeed(80);   // 数字越小滚得越快
  matrix.endText(SCROLL_LEFT);
}

void loop() {
}

要点只有几个：

  • matrix.begin()：初始化点阵
  • matrix.clear()：清屏
  • matrix.beginText(x, y)：开始写文字
  • matrix.print(...)：写数字/字母/字符串
  • matrix.endText()：显示静态文字
  • matrix.endText(SCROLL_LEFT)：左滚动显示

注意这块屏幕很小，UNO Q 是 8x13 点阵，能显示的字符非常有限： - 适合单个字母、单个数字、2 到 3 个紧凑字符 - 长字符串更适合滚动显示 - 英文字母和阿拉伯数字最合适 - 中文基本不适合直接显示

可以，自己画图形就是直接用官方图形接口，不走文字模式。

Arduino_LED_Matrix 继承了 ArduinoGraphics，所以你可以直接画： - point(x, y) 点 - line(x1, y1, x2, y2) 线 - rect(x, y, w, h) 矩形 - circle(x, y, d) 圆 - fill(...) / noFill() 控制是否填充 - stroke(...) / noStroke() 控制边框

官方接口定义： - Arduino_LED_Matrix 所在核心库：https://github.com/arduino/ArduinoCore-zephyr - ArduinoGraphics.h：https://raw.githubusercontent.com/arduino-libraries/ArduinoGraphics/master/src/ArduinoGraphics.h

最简单的例子，画一个边框、对角线和一个点：

#include <Arduino_LED_Matrix.h>

Arduino_LED_Matrix matrix;

void setup() {
  matrix.begin();
  matrix.clear();

  int w = matrix.width();
  int h = matrix.height();

  matrix.stroke(1);          // 开边框/线条
  matrix.noFill();           // 不填充

  matrix.rect(0, 0, w, h);   // 外框
  matrix.line(0, 0, w - 1, h - 1);
  matrix.line(w - 1, 0, 0, h - 1);
  matrix.point(w / 2, h / 2);

  matrix.endDraw();          // 有些板子不写也能显示，写上更稳妥
}

void loop() {
}

如果你想画“实心矩形”或者“实心圆”：

#include <Arduino_LED_Matrix.h>

Arduino_LED_Matrix matrix;

void setup() {
  matrix.begin();
  matrix.clear();

  matrix.stroke(1);
  matrix.fill(1);          // 开启填充

  matrix.rect(2, 1, 5, 4); // 实心矩形
  matrix.circle(10, 4, 3); // 实心圆
}

void loop() {
}

如果你想“逐像素”自己拼图案，最灵活的是 point() 或 set()：

#include <Arduino_LED_Matrix.h>

Arduino_LED_Matrix matrix;

void setup() {
  matrix.begin();
  matrix.clear();

  // 画一个心形示意
  int dots[][2] = {
    {3,1},{4,1},{8,1},{9,1},
    {2,2},{5,2},{7,2},{10,2},
    {3,3},{4,3},{5,3},{6,3},{7,3},{8,3},{9,3},
    {4,4},{5,4},{6,4},{7,4},{8,4},
    {5,5},{6,5},{7,5},
    {6,6}

  for (auto &p : dots) {
    matrix.point(p[0], p[1]);
  }
}

void loop() {
}

方案 1：继续用图标/动画，最符合 UNO Q 官方示例

if (weather_forecast == "sunny") {
