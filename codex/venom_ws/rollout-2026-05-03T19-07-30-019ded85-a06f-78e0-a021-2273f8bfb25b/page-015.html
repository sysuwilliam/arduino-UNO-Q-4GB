Assistant 2026-05-05T15:53:39.509Z

这是 rosdep 解析依赖时遇到两类问题：

  1. 项目里的 package.xml 写了不规范/不存在的 rosdep key
    例如 Eigen3、PCL、Boost、Armadillo 这些大小写写法在 rosdep 里通常不是这样。常见正确 key 是：
Eigen3     -> eigen
PCL        -> libpcl-all-dev 或 pcl_ros
Boost      -> boost
Armadillo  -> libarmadillo-dev
catkin     -> catkin

但这些多半来自 ego-planner-swarm、无人机相关包，不一定是你当前仿真导航必须依赖的。

  1. ros-humble-warehouse-ros-mongo 这个包在你的 apt 源里没有
    所以 apt 安装失败。它通常和 MoveIt warehouse/mongo 存储相关，不一定是你导航仿真必须要的。

如果你现在只是要跑这个仿真，不建议对整个 ~/venom_ws/src 跑 rosdep。先只对仿真项目跑：

cd ~/venom_ws
rosdep install -r --from-paths src/venom_vnv/simulation/venom_nav_simulation/src --ignore-src --rosdistro humble -y

如果还卡在 warehouse_ros_mongo，先跳过它：

cd ~/venom_ws
rosdep install -r \
  --from-paths src/venom_vnv/simulation/venom_nav_simulation/src \
  --ignore-src \
  --rosdistro humble \
  --skip-keys="warehouse_ros_mongo" \
  -y

如果仍然报那些无人机包的 key，说明你的 --from-paths 还是扫到了整个项目或子模块。可以进一步只构建你需要的包，例如：

cd ~/venom_ws/src/venom_vnv/simulation/venom_nav_simulation

rosdep install -r \
  --from-paths src \
  --ignore-src \
  --rosdistro humble \
  --skip-keys="warehouse_ros_mongo Eigen3 PCL Boost Armadillo zbar_interfaces yolo_interfaces launch_sim catkin cmake_modules ament_python" \
  -y

然后编译仿真相关包：

cd ~/venom_ws/src/venom_vnv/simulation/venom_nav_simulation
colcon build --symlink-install

重点：你现在不是系统缺了一堆基础库，而是这个大仓库里有些包的 package.xml 依赖声明不适配 rosdep。跑全仓库 rosdep install --from-paths src 很容易扫出一堆你当前用不到的包。

失败原因很明确：缺 livox_ros_driver2。

报错核心是：

Could not find a package configuration file provided by "livox_ros_driver2"

ros2_livox_simulation 编译时依赖 livox_ros_driver2，但你的工作空间或系统环境里没有这个包，所以 CMake 找不到。

先查一下源码里有没有：

cd ~/venom_ws
find src -maxdepth 5 -type d -name "livox_ros_driver2"

如果没有输出，就需要把 Livox 驱动放进工作空间。常见做法是：

cd ~/venom_ws/src
git clone https://github.com/Livox-SDK/livox_ros_driver2.git

然后先单独编译它：

cd ~/venom_ws
source /opt/ros/humble/setup.bash

colcon build --symlink-install \
  --packages-select livox_ros_driver2 \
  --cmake-args -DCMAKE_BUILD_TYPE=Release -DROS_EDITION=ROS2 -DHUMBLE_ROS=humble

编译完 source：

source ~/venom_ws/install/setup.bash

再回仿真目录编译：

cd ~/venom_ws/src/venom_vnv/simulation/venom_nav_simulation

colcon build --symlink-install \
  --cmake-args -DCMAKE_BUILD_TYPE=Release -DROS_EDITION=ROS2 -DHUMBLE_ROS=humble

如果你暂时只是想先把其他包编出来，可以先跳过 ros2_livox_simulation：

cd ~/venom_ws/src/venom_vnv/simulation/venom_nav_simulation

colcon build --symlink-install \
  --packages-skip ros2_livox_simulation \
  --cmake-args -DCMAKE_BUILD_TYPE=Release -DROS_EDITION=ROS2 -DHUMBLE_ROS=humble

但你这个仿真启动里会用 Livox 插件，所以最终还是建议把 livox_ros_driver2 装好。
