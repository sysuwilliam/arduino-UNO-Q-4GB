Assistant 2026-04-22T14:09:06.524Z

如果你是在 Linux 上装 Arduino IDE，默认下 AppImage。

原因很直接： - AppImage 是 Arduino 官方当前对 Linux 的默认安装方式，直接赋予可执行权限后就能运行。 - 它还支持 IDE 内更新，这一点比 ZIP 更省事。 - 官方帮助中心把 ZIP 归类为 portable installation 的额外选项。

只有这几种情况我才建议下 ZIP： - 你想把 IDE 解压到固定目录里，自己管理文件 - 你想保留多个版本并随时切换 - 你需要改 IDE 安装目录里的文件 - 你的系统跑 AppImage 时遇到 libfuse.so.2 / FUSE 相关问题

结论： - 大多数人：下 AppImage - 想手动管理、多版本共存、或 AppImage 跑不起来：下 ZIP

官方参考： - Arduino 安装说明: https://support.arduino.cc/hc/en-us/articles/360019833020-Download-and-install-Arduino-IDE - Arduino 下载页: https://www.arduino.cc/en/software

在终端里做这几步就行。

  1. 进入下载目录
cd ~/Downloads
  1. 给 AppImage 可执行权限
    把文件名替换成你实际下载的那个：
chmod +x arduino-ide_*.AppImage
  1. 运行
./arduino-ide_*.AppImage

如果想用图形界面： - 打开 Downloads - 右键这个 AppImage - 属性里勾选“允许作为程序执行” - 双击打开

如果打不开，常见是缺少 FUSE。可以先试：

./arduino-ide_*.AppImage --appimage-extract-and-run

另外，第一次用 Arduino 连板子时，Linux 可能还要串口权限：

sudo usermod -aG dialout $USER

然后 注销再登录。

如果你愿意，我也可以继续直接告诉你： - 怎么把它固定到应用菜单/桌面 - 怎么处理找不到开发板串口的问题
