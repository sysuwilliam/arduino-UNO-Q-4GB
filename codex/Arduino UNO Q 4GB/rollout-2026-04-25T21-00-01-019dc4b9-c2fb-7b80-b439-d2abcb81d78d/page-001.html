像你这个项目，Bricks 单独不够，更合适的是 OpenCV + 云台控制，必要时再把 App Lab/Bricks 当外层封装来用。

原因很直接。你的需求不是“识别这是什么物体”这么简单，而是这几步：

  1. USB 摄像头实时取流
  2. 在画面里找出一个指定多边形
  3. 提取顶点、几何中心、可能还要边中点/特征点
  4. 把像素坐标映射成云台角度
  5. 闭环控制激光打到目标点

Arduino App Lab 现在官方明确提供的视觉类能力，主要是这类高层 Brick： - camera_code_detection - imageclassification - objectdetection - video_imageclassification - video_objectdetection - 另外文档里还有 Custom AI Models 入口
来源： - App Lab 文档主页：https://docs.arduino.cc/software/app-lab/ - App Lab 软件页（截至我查询到的 2026-04-25 可见文档）：https://docs.arduino.cc/software - 官方 Bricks 仓库：https://github.com/arduino/app-bricks-py - 官方示例仓库：https://github.com/arduino/app-bricks-examples

这些 Brick 的共同特点是：更偏“分类/检测/扫码/视频 AI 推理”。我没有在官方文档和官方示例里看到针对你这种需求的现成 Brick： - 轮廓提取 - 多边形拟合 - 顶点排序 - 几何中心/形心计算 - 透视标定 - 像素坐标到云台坐标的几何映射

这句话里后半段是我的推断，但推断依据很明确：官方公开的 Brick 和示例都集中在“识别类别”，不是“做几何视觉测量”。

python3 -c "import cv2; print(cv2.__version__)"

如果报 ModuleNotFoundError: No module named 'cv2'，说明 Python 侧没装 OpenCV。

更稳的安装方式是先用 Debian 包管理器：

sudo apt update
sudo apt install -y python3-opencv

装完再验证：

python3 -c "import cv2; print(cv2.__version__)"

如果你还需要摄像头调试工具，通常可以顺手装：

sudo apt install -y v4l-utils

用来检查 USB 摄像头有没有被系统识别：

v4l2-ctl --list-devices

不建议你优先用 pip install opencv-python，原因是 UNO Q 是 ARM + Debian 环境，apt 版本通常更稳，依赖也更省事；只有在你确实需要更新版本、官方仓库版本太旧时，再考虑 pip。

  • 最可能需要你自己安装
