  • origin 指向官方仓库 Venom-Algorithm/Venom_VNV

  • origin 指向你自己的 fork
  • upstream 指向官方仓库

  1. 先在 GitHub 上 fork 官方仓库，得到你自己的 <your-name>/Venom_VNV
  2. 然后把你本地仓库的 origin 改成你的 fork
  3. 再把官方仓库加成 upstream

cd /home/william/venom_ws/src/venom_vnv
git remote rename origin upstream
git remote add origin git@github.com:<你的GitHub用户名>/Venom_VNV.git
git remote -v

如果你用 HTTPS，也可以写成：

git remote add origin https://github.com/<你的GitHub用户名>/Venom_VNV.git

调整完以后，理想状态是：

  • origin = 你的 fork
  • upstream = 官方仓库

之后同步官方最新代码：

git fetch upstream
git checkout master
git merge --ff-only upstream/master
git push origin master

再创建你自己的分支：

git checkout -b feat/<short-topic>

你现在不需要删仓库重下，只需要改 remote。
