def quaternion_from_euler(roll: float, pitch: float, yaw: float) -> tuple[float, float, float, float]:
    """Convert roll, pitch, yaw to quaternion."""
    cy = math.cos(yaw * 0.5)
    sy = math.sin(yaw * 0.5)
    cp = math.cos(pitch * 0.5)
    sp = math.sin(pitch * 0.5)
    cr = math.cos(roll * 0.5)
    sr = math.sin(roll * 0.5)

    w = cr * cp * cy + sr * sp * sy
    x = sr * cp * cy - cr * sp * sy
    y = cr * sp * cy + sr * cp * sy
    z = cr * cp * sy - sr * sp * cy
    return x, y, z, w

fork 在这里指 GitHub 上的“仓库分叉”。

意思是：

  1. 先把别人的仓库复制一份到你自己的 GitHub 账号下。
  2. 你在自己这份仓库里开发、提交代码，不直接往主仓库写。
  3. 改完后从你的 fork 向原仓库发 Pull Request，让原仓库维护者审核并合并。

典型流程是：

  1. 在 GitHub 页面点 Fork
  2. clone 你自己账号下那份仓库
  3. 新建分支开发
  4. push 到你自己的仓库
  5. 提交 PR 到原仓库

这么做的好处是权限边界清楚，适合协作开发，也不会直接污染主仓库。
