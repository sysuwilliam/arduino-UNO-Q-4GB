codex-export 已经在你机器上安装好了，路径是：

/home/william/.local/bin/codex-export

它默认从 ~/.codex/sessions 读取 Codex 会话记录，把 .jsonl 聊天记录转换成可浏览的 HTML。

常用命令

导出最近会话，并在列表里交互选择：

codex-export local

这会弹出最近 10 个会话供你选。默认输出到临时目录，并自动打开生成的 index.html。

导出最近更多会话供选择：

codex-export local --limit 30

导出到指定目录：

codex-export local -o ~/codex-exported

导出并把原始 .jsonl 一起复制进去：

codex-export local -o ~/codex-exported --json

自动按会话文件名创建子目录：

codex-export local -a -o ~/codex-exported

导出某一个具体会话

先找会话文件：

find ~/.codex/sessions -type f -name '*.jsonl'

然后导出指定文件：

codex-export json ~/.codex/sessions/2026/06/06/rollout-xxx.jsonl -o ~/codex-exported/my-chat

如果想导出后自动打开：

codex-export json ~/.codex/sessions/2026/06/06/rollout-xxx.jsonl -o ~/codex-exported/my-chat --open

导出全部 Codex 聊天记录

先预览会导出多少：

codex-export all --dry-run

你当前机器上 dry run 显示会导出 38 个会话，分布在 5 个 workspace。

真正导出全部：

codex-export all -o ~/codex-archive

导出完成后打开：

codex-export all -o ~/codex-archive --open

如果要包含 subagent/agent 会话：

codex-export all -o ~/codex-archive --include-agents

上传为 Gist

codex-export 也支持上传到 GitHub Gist：

codex-export local --gist

这需要你本机安装并登录 gh：

gh auth login

注意：聊天记录可能包含代码、路径、命令输出、私有项目内容，甚至误带的敏感信息。上传 Gist 前建议先本地导出检查 HTML 内容。

这是因为路径里有空格：Arduino UNO Q 4GB。Shell 会把它拆成多个参数，所以 codex-export 收到了多余的 UNO Q 4GB/codex。

把路径加引号即可：

codex-export all -o "/home/william/Desktop/Arduino UNO Q 4GB/codex"

或者转义空格：

codex-export all -o /home/william/Desktop/Arduino\ UNO\ Q\ 4GB/codex

建议用第一种，最不容易出错。运行成功后，入口文件会在：

/home/william/Desktop/Arduino UNO Q 4GB/codex/index.html

如果想导出后自动打开：

codex-export all -o "/home/william/Desktop/Arduino UNO Q 4GB/codex" --open
