你这台机器是 Ubuntu 22.04 (Jammy)，而且 ROS 2 Humble 的软件源已经可用，所以直接装就行。

如果你想装和 ROS 2 Humble 最常配的 Gazebo 集成，执行：

sudo apt update
sudo apt install ros-humble-gazebo-ros-pkgs

如果你还想把常见的 Gazebo 本体和示例一起补齐，可以再装：

sudo apt install gazebo

装完后先加载 ROS 环境：

source /opt/ros/humble/setup.bash

然后测试：

gazebo

如果你想测试 ROS 2 和 Gazebo 的联动，再试：

ros2 launch gazebo_ros gazebo.launch.py

补充一点： - 你机器上已经有 rviz2 - 我查到 ros-humble-gazebo-ros-pkgs 这个包在你的源里是可安装的 - 这套一般对应经典版 Gazebo 集成，适合先跑通 ROS 2 Humble

如果你愿意，我下一步可以直接帮你区分： - 装“经典 Gazebo” - 还是装“新版 Gazebo Fortress”
这两个命令不完全一样。

有区别。对你现在这台 Ubuntu 22.04 + ROS 2 Humble 的机器来说，实际是在选：

  • 经典 Gazebo：通常配 gazebo、gazebo_ros_pkgs
  • 新 Gazebo：Humble 官方推荐的是 Gazebo Fortress

简单判断：

  • 如果你只是想尽快跑 ROS 2 教程、老项目、网上现成示例，经典 Gazebo 更省事
  • 如果你是新开项目，想跟现在官方方向一致，Gazebo Fortress 更好

核心区别是：

  • 经典 Gazebo
  • 老生态，很多旧教程都在用
  • 和 gazebo_ros 这套接口绑定得很深

  • 上手资料多，但属于旧路线

  • Gazebo Fortress

  • 是新一代 Gazebo 体系，命令和桥接通常围绕 gz / ros_gz
  • 官方对 ROS 2 Humble 的推荐组合就是它
  • 后续生态方向更主流，但你会发现不少旧教程不能直接照抄

官方兼容表里，ROS 2 Humble + Gazebo Fortress 是推荐组合；而 Harmonic + Humble 可以用，但属于非默认方案，不建议新手直接上。
来源： - ROS 2 Humble 文档: https://docs.ros.org/en/humble/Tutorials/Advanced/Simulators/Gazebo/Gazebo.html - Gazebo 官方兼容表: https://gazebosim.org/docs/jetty/ros_installation/

我给你的直接建议是：

  • 学习 ROS 2、跟官方路线走：装 Gazebo Fortress
  • 想兼容老教程/老包：装 经典 Gazebo
  • Harmonic：先别选，除非你明确知道自己需要它

如果你要，我下一条可以直接给你两套安装命令： 1. 经典 Gazebo 安装命令
2. Gazebo Fortress 安装命令
你选一个直接执行就行。

Gazebo 已经启动了，但正在下载示例场景资源，所以界面在等。

[Dbg] [FuelClient.cc:2002] Downloading from a referral link [...]

GUI requesting list of world names. The server may be busy downloading resources. Please be patient.

意思就是： - GUI 已经起来了 - 但 world 还没完全加载完 - 一般是网络慢、资源服务器访问慢，或者下载卡住了

另外这条：

QML Connections ... are deprecated

只是 Qt/QML 的弃用警告，通常可以忽略，不是故障原因。

你现在可以这样判断：

  1. 先多等一会儿 第一次启动下载资源，几十秒到几分钟都有可能。

  2. 看窗口有没有真正弹出来 如果 GUI 窗口已经打开，只是场景空白，通常还是在加载。

  3. 如果一直卡住 多半是网络访问 Fuel 资源服务器慢。你可以先试一个不依赖在线资源的本地空场景：

ign gazebo empty.sdf

如果这个能正常打开，说明： - Gazebo 本体没问题 - 卡的是示例资源下载，不是安装问题

  1. 再确认 ign 是否可用
command -v ign

如果你想更稳地验证安装成功，我建议你现在直接试这条：

先把它分成两部分理解会更容易：单独用 Gazebo，以及 和 ROS 2 一起用。

单独用 Gazebo 你已经装的是 Humble 对应的 Fortress 这一代，常用入口是 ign gazebo。

最基本的命令：

source /opt/ros/humble/setup.bash
ign gazebo empty.sdf

这会打开一个空仿真世界。

再常见一点的用法：

ign gazebo shapes.sdf
ign gazebo -r empty.sdf

说明： - empty.sdf：空世界 - shapes.sdf：带几个基础模型的示例世界 - -r：启动后直接运行，不用手动点播放

如果你想先看看系统里有哪些示例 world，可以找一下：

find /usr/share -name "*.sdf" | grep gz

和 ROS 2 一起用 如果你想让 ROS 2 节点和 Gazebo 通信，核心是桥接包 ros_gz_bridge。常见流程是：

  1. 启动 Gazebo
source /opt/ros/humble/setup.bash
ign gazebo empty.sdf
  1. 另开一个终端，查看 ROS 2 话题
source /opt/ros/humble/setup.bash
ros2 topic list
  1. 如果有机器人模型或 launch 文件，再用 ros2 launch ... 启动机器人到 Gazebo 里

界面里怎么操作 Gazebo 打开后你一般会用到这些： - 左侧资源/模型面板：添加物体 - 中间 3D 视图：看场景 - 顶部播放按钮：开始、暂停、重置仿真 - 鼠标操作： - 左键拖动：旋转视角 - 中键拖动：平移 - 滚轮：缩放

最推荐你的入门顺序 1. 先跑空世界：ign gazebo empty.sdf 2. 再跑一个自带示例 world 3. 再学把机器人模型放进去 4. 最后再接 ROS 2 话题、传感器、控制器

你现在最该先试的命令

source /opt/ros/humble/setup.bash
ign gazebo empty.sdf

如果这条能正常打开，我下一步可以直接教你一个最小示例：
在 Gazebo 里放一个小车/盒子，然后用 ROS 2 看它的话题。
