  1. 环境前提：
  2. Ubuntu 22.04
  3. ROS 2 Humble

  5. colcon

cd ~

git clone --recurse-submodules https://github.com/Venom-Algorithm/Venom_VNV ~/venom_ws/src/venom_vnv
  1. 编译前先复制 Livox ROS2 包描述文件：
cp ~/venom_ws/src/venom_vnv/driver/livox_ros_driver2/package_ROS2.xml \
   ~/venom_ws/src/venom_vnv/driver/livox_ros_driver2/package.xml
  1. 安装依赖并编译：
cd ~/venom_ws
rosdep install -r --from-paths src --ignore-src --rosdistro $ROS_DISTRO -y
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release -DROS_EDITION=ROS2 -DHUMBLE_ROS=humble
  1. 编译完成后 source：
source ~/venom_ws/install/setup.bash
  1. 已有仓库时更新：
cd ~/venom_ws/src/venom_vnv
git pull
git submodule sync --recursive
git submodule update --init --recursive

文档还强调：如果旧工作区要重拉，先 cd ~ 再 rm -rf ~/venom_ws，避免当前 shell 落在被删除的路径里导致后续 git 报错。来源：https://venom-algorithm.github.io/Venom_VNV/home/quick_start/

可能可以，取决于你删的是哪个文件夹。

如果你删的是项目文件夹，比如 ~/venom_ws，通常不会删除 Codex 对话记录。可以直接试：

codex resume 019ded85-a06f-78e0-a021-2273f8bfb25b

如果能恢复，对话还在；只是工作区文件已经没了。

如果你删的是 Codex 的本地数据目录，比如类似：

~/.codex

那本地对话记录大概率也被删了，codex resume ... 可能就找不回来了，除非有备份、同步、终端 scrollback、shell 日志，或者你之前导出过。

你可以先检查本地是否还有会话记录：

ls ~/.codex

以及尝试搜索这个 session id：

find ~/.codex -type f -name '*' | xargs grep -l '019ded85-a06f-78e0-a021-2273f8bfb25b' 2>/dev/null

最简单判断：直接运行 codex resume 019ded85-a06f-78e0-a021-2273f8bfb25b。如果报找不到 session，把报错贴给我，我可以帮你判断还有没有恢复路径。
