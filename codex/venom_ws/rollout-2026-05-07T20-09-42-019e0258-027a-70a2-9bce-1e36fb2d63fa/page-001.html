按文档里的做法，给连接 Mid360 的有线网卡设静态 IP，走的是桌面网络设置界面：

  1. 点击左上角网络图标，进入 Settings
  2. 打开 Networks
  3. 找到 Wired，点右侧设置齿轮
  4. 进 IPv4
  5. 把 Method 从自动改成 Manual
  6. 填入：
  7. IP address: 192.168.1.50
  8. Netmask: 255.255.255.0
  9. Gateway: 192.168.1.1

文档同时说明，Mid360 默认地址通常是 192.168.1.1xx，所以主机和雷达要在同一网段里。WiFi 可以继续保持联网，不影响 SSH 或远程桌面。来源见官方文档的“配置网卡静态 IP”部分：

network proxy 就是“网络代理”。

它的作用是让你的电脑先把网络请求发给一个代理服务器，再由代理服务器去访问外网。常见用途是：

  • 统一公司/校园网出口
  • 访问被限制的内网资源
  • 做缓存、审计、过滤
  • 让某些程序走指定网络路径

一般有这些类型：

  • HTTP proxy：给网页和多数 HTTP 请求用
  • HTTPS proxy：给加密网页请求用
  • SOCKS proxy：更通用，很多程序都能用
  • Auto / PAC：自动配置代理规则
  • None：不使用代理

和你刚才说的静态 IP 不一样：

  • 静态 IP 是给网卡固定一个本机地址
  • Proxy 是给“上网流量”加一层中转

如果你只是想让雷达网卡和设备直连，通常 network proxy 不用管，保持关闭就行。

这页讲的是 Scout Mini / Scout Mini Omni 这类底盘的 CAN 总线部署，核心就是把 CAN-USB 适配器拉起来，然后启动底盘 ROS 2 节点。

按文档做，流程是：

  1. 首次配置 CAN 适配器 
bash ~/venom_ws/src/venom_vnv/driver/ugv_sdk/scripts/setup_can2usb.bash

这一步实际会做：

sudo modprobe gs_usb
sudo ip link set can0 up type can bitrate 500000
sudo apt install -y can-utils
  1. 之后每次重新插拔 CAN-USB 后，通常只需要重新拉起接口 
bash ~/venom_ws/src/venom_vnv/driver/ugv_sdk/scripts/bringup_can2usb_500k.bash
  1. 检查 can0 是否起来了 
ifconfig -a | grep can
ip -details link show can0
  1. 排查总线是否有数据 
candump can0
  1. 启动底盘 ROS 2 节点 
cd ~/venom_ws
source install/setup.bash
ros2 launch scout_base scout_mini_base.launch.py

如果是别的型号，文档还给了：

ros2 launch scout_base scout_base.launch.py
ros2 launch scout_base scout_mini_omni_base.launch.py
  1. 测试遥控 
ros2 run teleop_twist_keyboard teleop_twist_keyboard

文档里强调的关键参数是 bitrate=500000，而且主要适用于 scout_ros2 + ugv_sdk 这套底盘驱动。原文在这里：
底盘 CAN 部署
